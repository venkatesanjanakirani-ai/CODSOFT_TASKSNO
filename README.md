# CODSOFT Data Science Internship

This repository contains my tasks completed as part of the CODSOFT Data Science Internship.

## Task 1 - Titanic Survival Prediction

### Objective

Build a machine learning model to predict whether a Titanic passenger survived or not.

### Dataset

Titanic Dataset

### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

### Machine Learning Algorithm

Logistic Regression

### Project Workflow

1. Dataset Loading
2. Data Exploration
3. Missing Value Handling
4. Data Cleaning
5. Feature Encoding
6. Train-Test Split
7. Model Training
8. Prediction
9. Model Evaluation
10. Data Visualization

### Evaluation

The model was evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
