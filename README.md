# CODSOFT Data Science Internship

This repository contains the projects completed as part of my **CODSOFT Data Science Internship**.

The projects demonstrate the application of Python, data preprocessing, data visualization, machine learning, classification, regression, and model evaluation techniques.

---

## 📌 Tasks Completed

### Task 1 – Titanic Survival Prediction

**Objective:**  
Predict whether a passenger survived the Titanic disaster based on passenger information.

**Dataset Features:**
- Passenger Class
- Age
- Gender
- Fare
- Embarked

**Technologies Used:**
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

**Machine Learning Model:**
- Logistic Regression

**Steps Performed:**
1. Loaded the Titanic dataset
2. Explored the dataset
3. Handled missing values
4. Performed data preprocessing
5. Encoded categorical variables
6. Split the dataset into training and testing data
7. Trained a Logistic Regression model
8. Predicted passenger survival
9. Evaluated the model using accuracy and classification report
10. Visualized the results using graphs and confusion matrix

**Notebook:**  
`Titanic_Survival_Prediction.ipynb`

## 📈 Task 3 – Sales Prediction Using Python

**Objective:**  
Predict product sales based on advertising expenditure through different advertising platforms.

**Features Used:**
- TV Advertising
- Radio Advertising
- Newspaper Advertising

**Target:**
- Sales

**Technologies Used:**
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

**Machine Learning Model:**
- Linear Regression

**Steps Performed:**
1. Loaded the advertising dataset
2. Explored the dataset
3. Checked dataset structure and missing values
4. Performed descriptive analysis
5. Created correlation analysis
6. Visualized advertising expenditure against sales
7. Selected input features and target variable
8. Split the dataset into training and testing data
